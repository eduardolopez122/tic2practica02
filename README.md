# tic2practica02
 Este proyecto es un portfolio personal, hecho con la intención de dar una breve descrpción del creador de este trabajo y de servir de índice para los proyectos realizados. La intención es tener acceso a todo lo que se haga durante el curso.

## Estructura y apertura
- `index.html`: la página principal del proyecto.
- `estilos.css`: estilos propios de personalización.
- `img/`: imágenes utilizadas (avatar y fondo).

Para acceder a la web se debe ejecutar `index.html` o entrar en `https://salescoruna.ddns.net/eduardo.lopez` en un navegador.

## Tecnologías
- HTML5: estructura y organización del contenido.
- CSS3: diseño y personalización visual.
- Bootstrap 5.3: tarjetas, menú, acordeones, carrusel y tablas.
